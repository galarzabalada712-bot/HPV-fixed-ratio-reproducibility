# Additional input fields and output mappings

`data_dictionary.csv` describes all 133 fields in the frozen candidate cohort. Raw NHANES field names also require the official cycle-specific codebooks for exact answer labels, skip patterns and release restrictions.

| File / field | Meaning |
|---|---|
| `model_covariates.csv / sexagenew` | Age at first sex, 1 below 18 years, 2 at least 18 years; unavailable, refused and do-not-know set missing. Earlier and later source question wording differs. |
| `model_covariates.csv / sextotal` | Female lifetime male partners, 0=0, 1=1, 2=2–5, 3=6–10, 4=>10; unavailable, refused and do-not-know set missing. |
| `fixed_HPV_sample_preflight_by_person.csv / CRP_raw` | Public source CRP value in the cycle's original unit; earlier values mg/dL and 2015–2016 mg/L. |
| `fixed_HPV_sample_preflight_by_person.csv / CRP_mg_L` | CRP after multiplying 2003–2010 values by 10; 2015–2016 values unchanged; 2011–2014 missing. |
| `survey_design_frame.csv / design_stratum` | Cycle start joined to SDMVSTRA; SDMVPSU is nested within the resulting stratum. |
| `models/model_status.csv / D` | β_A + β_B for the two original unstandardized log components. |
| `models/model_status.csv / p, Holm_7` | 1-df survey design-adjusted working LRT P; Holm-adjusted P across 7 independent constraints within an outcome. Wald CIs are not multiplicity-adjusted. |
| `HPV_performance.csv / delta_auc` | Fitted-sample weighted AUC of component model minus fixed-composite model. |
| `HPV_bootstrap_replicates.csv` | Paired survey bootstrap ΔAUC, continuous NRI and IDI for 14 markers and 1,000 repeats each. |
| `CLR_MI_results.csv / Wald_p` | Rubin-pooled Wald P for 20 imputations; only three 2015–2016 CRP values were imputed. |
| `simulation/output/summaries/scenario_grid_calibrated.csv` | Scenario parameters, sample sizes, correlations, target effects and calibration information. |

Table mapping: Table 1 is computed in the two Table 1 CSVs; Table 2 corresponds to `models/model_status.csv` and `reference/constraint.csv`; Table 3 and Supplementary Table 3 use the simulation summary/table CSVs. Supplementary Table 1 uses `HPV_performance.csv`; Supplementary Table 2 uses the CLR CSVs. HPV AUC and DCA figures are regenerated by `hpv_extra_covariates_figures_20261102.R` using the performance and decision-curve sources. Figure 1 is supplied only as the historical PDF.
